# Mapa de formatos · ¿Qué forma puede tomar una idea?

La Mesa de Trabajo no parte de una tecnología favorita. Parte de una pregunta, una emoción, una historia o algo que merece ser contado. Este mapa ayuda a descubrir qué formato podría servir mejor.

## Si la idea necesita ubicar cosas en el territorio
- **Mapa ilustrado:** para una lectura visual y sencilla.
- **Mapa histórico interactivo:** para abrir fichas, imágenes, documentos y relatos desde lugares concretos.
- **Mapa sonoro:** para escuchar ambientes y voces.
- **Recorrido digital o impreso:** para acompañar a una persona de un punto a otro.
- **Antes / ahora:** para comparar cambios con fechas y fuentes.

## Si la idea necesita contar una historia
- **Libro o cuadernillo:** cuando el relato necesita continuidad y puede leerse sin conexión.
- **Historieta:** cuando personajes, escenas y secuencias ayudan a comprender.
- **Línea de tiempo:** cuando el orden de los hechos importa.
- **Documental o video breve:** cuando la voz, la imagen real y el ambiente son esenciales.
- **Podcast o pieza radial:** cuando escuchar es más importante que mirar.
- **Archivo de testimonios:** cuando interesa conservar voces y recuerdos con consentimiento.

## Si la idea necesita enseñar o ayudar a reconocer
- **Atlas o fichas visuales:** para consultar información por partes.
- **Lámina o infografía:** para comprender una relación de un vistazo.
- **Guía de observación:** para salir, mirar y registrar.
- **Actividad imprimible:** para escuelas o personas con conectividad limitada.
- **Mini sitio web:** para explorar contenido organizado sin una aplicación compleja.

## Si la idea necesita participación o decisiones
- **Juego narrativo:** para aprender mediante elecciones, descubrimientos y consecuencias.
- **Prototipo interactivo:** para probar una mecánica antes de construir el proyecto completo.
- **Formulario o buzón de ideas:** para recoger aportes con propósito y reglas claras.
- **Exposición o instalación:** para compartir en un espacio físico.
- **Taller o encuentro:** cuando conversar y hacer juntos es el núcleo de la idea.

## Si la idea necesita ser vista o sentida
- **Dibujo e ilustración:** para interpretar, explicar o imaginar.
- **Fotografía:** para observar y documentar, cuidando contexto y permisos.
- **Collage y experimentación gráfica:** para investigar una identidad visual.
- **Animación:** para mostrar transformación, movimiento o relaciones.
- **Paisaje sonoro:** para transmitir una atmósfera que una imagen no alcanza a contar.

## Cómo elegir sin enredarse

Preguntarse:

1. ¿Qué quiero que la persona descubra, sienta, recuerde o haga?
2. ¿Qué material tengo de verdad: imágenes, documentos, voces, observaciones, dibujos?
3. ¿La persona necesita internet, impresión, audio, pantalla grande o solamente el teléfono?
4. ¿Qué formato deja más clara la idea con menos barreras?
5. ¿Cuál es la prueba más pequeña que puedo hacer para comprobarlo?

### Escalera de creación

**Chispa → pregunta → material disponible → formato posible → prueba pequeña → revisión → obra.**

La programación aparece cuando la interacción digital aporta algo real. Un libro no necesita convertirse en una app; un mapa no tiene que convertirse en un juego; una idea híbrida puede combinar formatos si eso mejora lo que comunica.

## Cuidado y confianza

- Separar información documentada, testimonios, interpretación artística e hipótesis.
- Citar fuentes y registrar permisos cuando corresponda.
- Respetar la privacidad y la dignidad de las personas.
- En naturaleza, evitar prácticas dañinas y la difusión de ubicaciones sensibles.
- Pensar en celulares, lectura fácil, impresión y conectividad limitada cuando el público lo necesite.

**Este mapa orienta, no obliga. La idea puede encontrar una forma que todavía no aparece aquí.**
