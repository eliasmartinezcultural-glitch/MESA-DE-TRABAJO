# Buzón de chispas

Este es el lugar para anotar una idea apenas aparece, sin tener que resolverla ni clasificarla perfectamente. Puede ser una frase, una imagen mental, una pregunta, un lugar, un personaje, un documento que falta o una combinación extraña de formatos.

## Captura rápida

Copia este pequeño bloque cada vez que aparezca algo nuevo:

- **Fecha:**
- **La chispa, tal como apareció:**
- **¿Qué me la disparó?**
- **¿Qué parte de San Patricio del Chañar toca?** Historia / comunidad / fauna / flora / turismo / cultura / territorio / otra.
- **¿Qué me imagino que podría ser?** Mapa / libro / dibujo / juego / web / app / audio / video / encuentro / no sé todavía.
- **¿Qué me gustaría descubrir?**
- **Un primer paso diminuto:**
- **Estado:** recién llegada / explorando / en pausa / probada / convertida en proyecto.

## Ideas capturadas

*Todavía no hay entradas registradas en este buzón. Agregá aquí las nuevas chispas cuando aparezcan.*

---

## Permiso para dejar cosas incompletas

No hay obligación de transformar cada idea en proyecto. Este buzón existe para que la inspiración no se pierda y para que puedas volver a ella cuando tenga sentido.
