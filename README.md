# MESA DE TRABAJO · OCARINA PRODUCCIONES

**Centro de operaciones para crear, cuidar, revisar y mejorar los proyectos digitales, culturales y audiovisuales de Ocarina.**

> Principio central: más capacidad detrás; una experiencia clara, rápida, accesible y cuidada delante.

## Para qué sirve

Esta mesa organiza el trabajo entre ideas, investigación, contenidos, diseño, programación, pruebas y publicación. No reemplaza los proyectos existentes: les aporta un método común, sin migrarlos ni modificarlos automáticamente.

## Reglas de trabajo

1. **No romper lo que funciona.** Antes de tocar un proyecto existente, identificar su estado, leer su documentación y preparar un cambio acotado y recuperable.
2. **No publicar por sorpresa.** Las comprobaciones automáticas pueden analizar cambios, pero no deben desplegar sitios ni modificar otros repositorios.
3. **Verificar antes de afirmar.** Distinguir entre implementado, probado, publicado y pendiente.
4. **Primero la experiencia real.** Probar en móvil y escritorio; priorizar claridad, carga rápida, legibilidad y navegación sencilla.
5. **Contenido curado.** Registrar fuentes, fecha de consulta, autoría, permisos de uso y nivel de certeza.
6. **No inventar datos ni recursos.** Si una fuente, foto, enlace o función no se verificó, indicarlo como pendiente.
7. **Gratuidad por defecto.** Elegir herramientas gratuitas y estáticas cuando alcancen; evaluar costos antes de incorporar servicios.
8. **Cambios pequeños y reversibles.** Un objetivo por cambio, copia/commit identificable y pruebas antes de cerrar.
9. **Respetar las reglas particulares.** Si un proyecto está congelado o tiene límites propios, esos límites prevalecen sobre esta guía.
10. **Autoría transparente.** Dar crédito a Elías Martínez / Ocarina Producciones donde corresponda y respetar licencias de terceros.

## Flujo de trabajo recomendado

**Idea → ficha de proyecto → investigación → prototipo → revisión de contenido → prueba técnica → revisión visual → aprobación → publicación → seguimiento.**

## Automatización

El control de calidad se ejecuta en GitHub Actions ante cambios en este repositorio, en solicitudes de integración o manualmente. **No publica sitios, no toca otros repositorios y no modifica datos.**

## Alcance y límites

Esta mesa es un centro de método y documentación, no una conexión mágica entre todos los servicios. Las integraciones externas, permisos, secretos, dominios, Pages y automatizaciones de cada proyecto deben comprobarse por separado. No se guardan contraseñas, tokens ni claves en el repositorio.
