# Control previo a publicar

## Contenido
- [ ] Propósito y público claros.
- [ ] Nombres, fechas, cifras y topónimos revisados.
- [ ] Afirmaciones importantes respaldadas por fuentes.
- [ ] Testimonios, hipótesis y recreaciones identificados.
- [ ] Fotos, mapas, audio, tipografías y textos tienen permiso/licencia comprobados.
- [ ] Créditos y referencias visibles donde corresponda.
- [ ] No hay información personal sensible publicada sin necesidad y permiso.

## Diseño y uso
- [ ] La entrada explica qué ofrece el proyecto.
- [ ] La acción principal es fácil de identificar.
- [ ] Se puede leer y usar en móvil y escritorio.
- [ ] No hay texto, controles ni imágenes superpuestos.
- [ ] Imágenes cargan, están bien encuadradas y tienen alternativa textual útil.
- [ ] Contraste, foco de teclado y tamaños de controles son razonables.
- [ ] Enlaces externos se identifican y funcionan.

## Técnica y seguridad
- [ ] No hay claves, tokens ni secretos en el código.
- [ ] Rutas y enlaces internos revisados.
- [ ] Consola y errores visibles revisados cuando sea posible.
- [ ] No se añadieron dependencias innecesarias.
- [ ] No se modificaron otros proyectos ni automatizaciones ajenas.
- [ ] Hay commit/versionado y una vía de recuperación.

## Aprobación
- [ ] Pruebas documentadas.
- [ ] Pendientes y limitaciones declarados.
- [ ] Publicación autorizada.
- [ ] URL publicada comprobada después del despliegue.
